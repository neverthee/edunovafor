# EduNova Backend

This directory contains the Flask backend for EduNova. It exposes the APIs used by the Vue frontend and also hosts the RAG, parsing, document generation, and background task logic.

## What lives here

- `api/` for HTTP endpoints
- `models/` for SQLAlchemy models
- `rag/` for retrieval, parsing, and lesson-plan generation
- `tasks/` for background jobs
- `templates/` for DOCX/PPT templates and environment examples
- `uploads/` for runtime files generated by the backend

## Setup

1. Install dependencies from the repository root:

```powershell
python -m pip install -r requirements.txt
```

2. Create `backend/.env` from `backend/templates/.env.example`.

3. Set the runtime secrets and model configuration in `backend/.env`.

Example values:

```env
SECRET_KEY=replace-with-your-own-secret
JWT_SECRET_KEY=replace-with-your-own-secret
LLM_API_KEY=your-api-key
LLM_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
MODEL_TEXT_PRIMARY=qwen-flash
MODEL_EMBEDDING_PRIMARY=text-embedding-v4
MODEL_RERANK_PRIMARY=qwen3-rerank
MODEL_OCR_PRIMARY=qwen-vl-ocr-latest
MODEL_ASR_PRIMARY=qwen3-asr-flash-realtime
```

## Running

From the repository root:

```powershell
.\start_backend.bat
```

The backend listens on `http://127.0.0.1:5001` by default.

## Notes

- Do not commit `.env`, local virtual environments, cache folders, or generated upload outputs.
- `backend/init_db.py` is destructive and resets the SQLite database.
- To clear demo AI chat history while keeping other demo data, run `python backend/clear_chat_history.py`. Add `--vacuum` if you also want SQLite to reclaim file space after deletion.
